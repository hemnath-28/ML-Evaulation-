# Machine Learning Evaluation

This project evaluates machine-learning algorithms for classification and regression tasks.

## Repository structure

```text
.
├── README.md
├── requirements.txt
├── data/                 # Raw datasets or download scripts
├── notebooks/            # Analysis and model-evaluation notebooks
│   ├── classification.ipynb
│   └── regression.ipynb
├── models/               # Saved trained models (optional)
└── app/                  # GUI or deployment code (optional)
```

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Open the notebooks from `notebooks/` with Jupyter or VS Code.
